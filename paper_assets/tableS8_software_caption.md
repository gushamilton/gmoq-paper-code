# tableS8_software

Table S8. Software and versions. One row per software package used for the results reported in the paper, with its release and the analyses it served (Methods). The earlier G-MoQ Stage 2 release produced the analyses listed against it; its default output is identical to the current release. Versions are those recorded in the analysis environment. Test, file-format and plotting software are not listed. BMI, body mass index; GWAS, genome-wide association study; LD, linkage disequilibrium; LDSC, LD score regression.

Source data: results/09_software/versions.
