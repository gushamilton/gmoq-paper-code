# tableS1_simulation_design

Table S1. Design of the simulation studies. One row per study, described by its aim, data-generating mechanism, estimand, the methods compared and the performance measures (Supplementary Note 1). Every Stage 1 analysis used the 45 quantile levels 0.02–0.98 of the empirical analyses and, for the jackknife, 1,000 blocks with individuals assigned at random; studies 1–6 used 1 CPU thread for timings. Numerical results are in Supplementary Table S2. N, simulated sample size; RIF–OLS, recentred influence function ordinary least squares; RMSE, root mean square error; s.d., standard deviation; SE, standard error; U(a, b), uniform distribution on [a, b].

Source data: results/08_simulations/summary, results/02_mixtures/weight_design/sim.
