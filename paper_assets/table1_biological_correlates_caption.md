# table1_biological_correlates

Table 1. Biological correlates of scale-invariant dimensionality in UK Biobank quantitative traits. Dimensions and PC2 ratios use the primary one-shape null, as in Figure 6b. Correlations are Pearson r across selected lead variants in the same cohort; two-sided P values in the source data are nominal. HbA1c correlations use unit-length whitened PC2 directions; other correlations use unnormalised whitened PC2 projections. The no-diabetes HbA1c component ratio uses raw HbA1c; the separate asymmetry count uses log HbA1c. The restricted-panel asymmetry counts do not imply a change in primary component dimensionality.

Source data: results/06_traits/moments, results/06_traits/hidden_biology, results/07_hba1c/skew_diabetes.
