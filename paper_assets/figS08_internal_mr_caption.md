# figS08_internal_mr

Figure S8. Internal Mendelian randomisation between G-MoQ sex components and sex-stratified REGENIE. Each point is the inverse-variance-weighted slope (fixed effect, through the origin) relating the G-MoQ Stage 2 female or male component effect on testosterone (rows) to the sex-stratified REGENIE effect in the same sex, for the unshrunk analysis and three shrinkage settings (Methods); bars, 95% confidence intervals; numbers, instrument variants per estimate. Columns give the direction: REGENIE → G-MoQ uses independent REGENIE lead variants as instruments and G-MoQ → REGENIE uses independent genome-wide significant (P < 5 × 10⁻⁸) Stage 2 lead variants (Methods). Dashed line, slope = 1, exact agreement with the sex-stratified reference. n = 399,710 participants (199,572 female, 200,138 male); the reference uses the same phenotype, covariates and leave-one-chromosome-out predictions as Stage 1. Comparisons with the reference under both mixture weight designs are given in Supplementary Table S3; the designs are compared in Supplementary Fig. S7. CI, confidence interval; IVW, inverse-variance weighted.

Source data: results/03_testosterone/recovery.
